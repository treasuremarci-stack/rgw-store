## Политика проверки

Автоматически подключались только изображения с домена производителя или его официального медиакаталога, когда страница/ассет позволяли сопоставить товар с конкретной моделью. Изображения сторонних магазинов и маркетплейсов не копировались. Все подключённые файлы локализованы в `images/products/PRODUCT_ID/`, конвертированы в WebP и прописаны в `products.json`.

Официальный источник сам по себе не является отдельным подтверждением лицензии на повторное размещение. Поэтому для подключённых изображений явно отмечена ручная проверка условий использования. Для остальных товаров заглушки сохранены: похожая модель не использовалась.

## Проверка опубликованного сайта

- `product.html?id=mice-3` открыт на GitHub Pages: четыре миниатюры загрузились, нажатие на вторую миниатюру изменило главное изображение с `main.webp` на `02.webp`.
- Главное изображение отображается с `object-fit: contain`; фактическая область 446×430 px, исходник 1400×1202 px, растягивания за контейнер нет.
- Карточка `mice-3` в `rgw_page_mice.html` использует локальный `images/products/mice-3/main.webp`.
- Ложные признаки битых нижних изображений при первом просмотре были вызваны `loading="lazy"`; после попадания карточки в область загрузки файл `mice-7/main.webp` открылся с натуральным размером 800×687 px.
- Ошибок JavaScript сайта при проверке не обнаружено; сообщения расширения облачного браузера к коду АКС не относятся.
- Отдельная автоматическая эмуляция мобильного Chromium в локальной среде не выполнена: исполняемый файл браузера отсутствует. Адаптивные правила 900/760/560 px и ограничения изображений проверены по коду.
