# RGW — Каталог компьютерной техники

Множество страниц каталога для локального магазина компьютерной техники.

## Страницы

- **rgw_multipage_home.html** — главная страница и глобальный каталог категорий
- **rgw_page_laptops.html** — категория ноутбуков с фильтрами
- **rgw_page_keyboards.html** — категория клавиатур
- **rgw_page_headphones.html** — категория наушников
- **rgw_page_mice.html** — категория мышек

## Функции

✅ Адаптивный дизайн (мобильный + десктоп)
✅ Работающая фильтрация товаров
✅ Сортировка по цене, характеристикам
✅ Сворачиваемые группы фильтров
✅ Отображение активных фильтров
✅ Пустое состояние при отсутствии результатов

## Как открыть

1. Клонируй репозиторий
2. Открой любой HTML-файл в браузере
3. Или используй локальный сервер (например, `python -m http.server 8000`)

## Структура

Жиёвая фильтрация реализована на чистом JavaScript без зависимостей.
