# Проверка каталога перед импортом

Файл validate_catalog_import.mjs — автономный инструмент без сторонних зависимостей. Он читает только существующие файлы и формирует отдельный JSON-отчет.

Из корня репозитория:

~~~bash
node tools/validate_catalog_import.mjs . reports/catalog-import-report.json
~~~

Параметры:

- первый аргумент — корень репозитория;
- второй аргумент — путь JSON-отчета;
- --strict — завершить процесс с кодом 1, если найдены ошибки;
- --baseline-products path/to/products.before.json — сравнить набор ID с предыдущей версией.

Проверяется:

- количество товаров, обязательные поля, формат и дубликаты ID/SKU;
- наличие catalogFacts, categoryUrl и локальных файлов изображений;
- корректность числовых цен и заголовка price.csv;
- приблизительное сопоставление названий товаров с ценовыми строками;
- ссылки всех rgw_page_*.html на существующие ID;
- связь categoryUrl с реальной страницей и наличие карточки;
- сохранность ID при переданном baseline-файле.

Скрипт не изменяет products.json, price.csv, HTML и изображения. Предупреждения о неполному совпадении цены или отсутствующем verifiedSpecs не блокируют обычный запуск; режим --strict блокирует только ошибки.
